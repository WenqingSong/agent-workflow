# Workflow V5.0.0 — V3.4.0 基线版本跃迁

> 发布类型：Major version marking（版本标记 / 品牌跃迁），不是 Engine 功能重构。
>
> V5.0.0 从当前 `main` 的 V3.4.0 基线切出，保留五个 Gate、七角色路线、`state.yaml` schema 3、Engine 行为与 Git 证据模型。历史 V3.x Release Notes 与 Task 证据保留为历史记录，不随本次跃迁改写。

- `.agent/VERSION` 从 `3.4.0` 跃迁为 `5.0.0`；
- 顶层 README、Package Manifest、Architecture Design、LLM Project Context、Runtime README 同步为 V5.0.0；
- 发布资产命名切换为 `workflow-check_5.0.0_<goos>_<goarch>[.exe]`、`agent-workflow-src-5.0.0.tar.gz`、`agent-workflow-release-notes-5.0.0.md`；

- `.cnb.yml` 中的发布配置文本同步为 `v5.0.0`，但流水线仍保持 Owner 注释停用状态；
- 历史 `docs/releases/v3.1.0.md` 至 `v3.4.0.md` 保留，不删除、不改写。

## 5. 已知边界

- 本次是版本标记 / 品牌跃迁，不是 Engine 行为变更；不得据此推断 V5 新功能。
- CNB 发布与镜像流水线当前已注释停用；本 Release 由手工流程创建。`version.json` 的 `published_status` 仍按构建时契约为 `NOT_RELEASED`，平台发布状态以 CNB Release 与附件核验为准。
- 四平台 Binary 中仅 Linux x86-64 在构建环境真实执行过；其余为交叉编译与静态校验，不构成运行时保证。
- GitHub 镜像不属于本次发布范围；如需同步，仍需 GitHub 写权限。
